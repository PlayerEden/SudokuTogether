## What changed

- Co-op displays the higher-priority equipped board from both room appearances. The order from lowest to highest is Classic, Linen, Midnight and Circuit. A reserved partner's theme stays eligible while they are away. A change to a player's equipped appearance can update the room's theme. Each player's own ink and font are used on their entries, with the uniform-number preference supported. Solo, Daily and Versus use the local board theme. [Theme design](GRIDMATES_SHARED_COOP_BOARD_THEMES_DESIGN.md)
- Versus results show the winner, both players' filled counts and the local player's board at the finish. The host can start the next race in the same room when both players are present. Returning guests confirm readiness through the existing foreground status message. The host checks the expected race epoch and completion state when committing a restart. The wire protocol and saved session format remain compatible with v0.11E. [Versus design](GRIDMATES_VERSUS_POST_MATCH_COMPARISON_DESIGN.md)

## Physical playtest

1. On each phone, open the same QA APK and choose **Update** for the existing Sudoku installation. Connect both phones to the same Wi-Fi.
2. Equip an earned board on one phone and Classic on the other. Join a Co-op room. Check the shared look and each player's number styles, then leave and rejoin with the same partner.
3. Finish a Versus race and check the result on each phone. Have the guest leave and rejoin before the host chooses **Next race**. Check that both phones open the new puzzle and can play.
4. Open room chat and tap a quick reply with the keyboard closed. Check the finish screen with large text and TalkBack on a current Android phone. Record physical multiplayer, accessibility and Play testing in the [delivery plan](GRIDMATES_DELIVERY_PLAN.md).
