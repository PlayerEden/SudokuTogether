## Verification

- 125 JVM tests and 13 APK preflight tests passed. Lint reported zero errors and 16 warnings. The Android workflow YAML and shell blocks passed static validation.
- The original v0.11D file, code 20, was seeded on an Android 8 emulator. Android accepted the v0.11E APK as an update. The installed bytes matched both artifacts and Android retained the first-install timestamp. The seeded Solo and Daily progress, records, identity, cosmetics, settings and protected room survived. The rebuilt APK passed the same rehearsal again.
- The candidate passed 30 targeted Android 8 instrumentation cases, including the post-update check, 23 backup and local-save cases, two Settings backup cases, and four Profile and Collection cases. They cover malformed data, interruption recovery, preview cancellation, locked icon progress, and explicit equip.
- The QA rebuild reproduced the same tested APK byte for byte. The production APK and App Bundle were rebuilt and signed locally with the original production key. The production APK certificate and package matched. Strict JAR signature verification and Bundletool validation passed for the delivered App Bundle, and Bundletool generated its installable splits.
- The QA app exported its seeded save through Android's file picker. Bundletool installed the production base and its language, density and x86 splits on the same Android 8 emulator. The production app opened that file in the picker, previewed and restored it, and resumed the Solo puzzle with the exact seeded entry and pencil note. The UI probe needed a retry after file selection.

## Test on phones and in Play Console

1. Update the current QA installation to v0.11E. Reopen an unfinished puzzle, then visit **Profile**, **Collection**, and **Settings → Progress**.
2. On two matching builds, verify co-op and Versus from discovery through completion. Include optional codes, both players editing, pause and reconnect, and a rematch.
3. Check modern Android orientation, system Back, large text, TalkBack, and Daily rollover on real devices. The hosted API 36 visual and production workflow runs are open.
4. Complete Play Console signing enrollment, listing and disclosures, and account-specific test track acceptance. [Launch guide](GOOGLE_PLAY_FROM_SCRATCH_LAUNCH_GUIDE.md)
