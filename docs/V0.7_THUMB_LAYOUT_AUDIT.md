# Sudoku Together v0.7 -- Mobile thumb reach & screen-space audit

Branch: `polish/v0.7-thumb-layout`, based on the v0.6 native puzzle feel pass.

## UX observation and decision

The v0.6 actual Android screenshots show the 9×9 grid already consumes nearly all horizontal space. Enlarging every element would reduce clarity. The key problem is that the number/action controls sit inside the same vertically scrolling content as the board. They drift up on tall phones, waste space below, and can disappear offscreen on shorter phones.

## Changes

- Restructured the native **Play** screen as a vertical two-region layout:
  - **Scrollable puzzle region**: title, status, near-max-width board, partner presence, saved/room details, result card.
  - **Fixed bottom input dock**: Notes, Erase, Undo and two number rows; stays thumb-accessible in tall and compact layouts.
- Board width may use 24dp rather than 32dp total horizontal guard space and uses its available vertical area conservatively.
- Input dock is visually separated by a thin border on an opaque surface, while respecting Android safe drawing insets supplied by SudokuApp.
- Disabled controls retain correct state, and solved games hide the dock in favor of the existing completion/replay panel.
- Emulator UI smoke checks assert the fixed input dock is displayed and handle the real saved-solo confirmation dialog.
- Version updated to v0.7.0-dev / code 7; separate `.qa` package retained.
