# Sudoku Together v0.3 — Chat + earned identity (draft)

This is a *stacked development branch* based on the v0.2 solo/versus/records draft, which itself builds on the v0.1 local co-op implementation. It is not yet a verified APK.

## Implemented

### Local Wi-Fi room chat

- In co-op and versus, a small **Chat** action opens a Material bottom sheet. The full Sudoku grid is not permanently displaced by a chat sidebar.
- Each participant can send up to 160 visible characters; the host creates a room-authoritative `ChatLine` with actual sender identity, timestamp and message ID. A guest cannot claim to be the host by setting a sender field.
- Shortcuts: **Nice move!**, **Need a hint?**, **Good game!**, **Rematch?**. A basic 650ms per-sender interval helps prevent message flooding.
- Up to 30 messages stay in host memory and are delivered when a guest rejoins; they are not permanent transcripts or profile history.
- Chat works on local Wi-Fi without internet or an account. Traffic is **not encrypted** and is suitable for a trusted home network, not public networks.

### Earned cosmetic collection

- Player profile exposes **Number colors, Board styles, Number fonts**, with available items and requirements for locked items.
- All options use named catalog identifiers. No untrusted assets, external font files, custom color expressions, or downloads are transmitted.
- Starter: Forest color, Classic board, Clear typeface.
- Number colors: Cobalt at 1 solo solve; Amber at 3; Rose at 5; Violet at 2 versus wins.
- Boards: Linen at 2 solo solves; Midnight at 5; Circuit at 3 versus wins.
- Fonts: Bookish at 1 solo solve; Terminal at 2 completed co-op puzzles.
- Unlocks are derived from on-device completed-game records, not separate counters. Selection is persisted in Android preferences. There is no account/cloud synchronization or cross-device verification yet.

### Attribution and display

- `Cell.owner` stores which player last edited an editable cell. In co-op, player-entered numbers display that author's color and font on both phones. Fixed clues are always neutral.
- Notes keep an author marker; undo restores the prior cell **including** its author, so another person's previous work regains their styling.
- The board background/style is chosen by each local viewer (avoiding conflicting two-theme backgrounds). The partner's equipped color, board, and font are shown on a small identity label.
- In versus each board remains private. The opponent's **equipped appearance** is shared, but their guesses, notes and hidden board are **not** exposed.
- Built-in Android/Compose font families (Sans, Serif, Mono) avoid binary font licensing and packaging problems. Conflict color takes precedence over earned colors, and readable neutral clues remain visually distinct.
- The established co-op and race save formats retain defaults for older sessions. Protocol is now **v3**, and Android test release version is `0.3.0-dev` (versionCode 3). Both Wi-Fi players must upgrade together.

## Verification status

Added `CosmeticsChatTest` for unlock conditions, authorship after undo, authenticated host/guest chat and message bounds. Added Android UI smoke coverage for cosmetic collection and chat sheet.

**Not yet executed**: full Gradle core tests, Android unit tests, lint, debug/release assemble, emulator UI test, physical two-phone test and APK signing. No GitHub Actions minutes have been consumed.

### Suggested local verification

```bash
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Follow with connected Android tests and a two-phone session on the same Wi-Fi. In particular verify:

1. Install as an update signed with the same key; load older v0.1/v0.2 saved rooms, solo saves and records.
2. Open Chat on both phones; send/receive messages, test emojis, rapid send, long text, rotate, keyboard opening, close/reopen, disconnect/rejoin.
3. Ensure the guest cannot spoof message author, flood the host, or see private versus numbers inside protocol/outcome payloads.
4. In co-op, enter a number as host, overwrite it as guest, then undo; verify both phones consistently show the corresponding writer's font/color.
5. Start a versus race; check only opponent's equipped styles and fill count are revealed, not their answers.
6. Earn a one-solve unlock in solo, equip it in the profile, restart app, verify selection persists, and join a Wi-Fi room to check the other player sees it.
7. Check board colors, conflicts, clues, notes, color distinction and min/max Android font scaling on light/dark boards.
8. Confirm no appearance changes alter Sudoku solutions, accepted moves, score, timer, race outcomes or winner rules.

## Out-of-scope suggestions for later

- More cosmetic categories: avatars, themed pencil marks, subtle completion effects, seasonal sets, victory poses, and public player profile showcase.
- An **optional** shared-board styling switch that lets players force a unified classic/high-contrast board when color/font mixing hurts readability.
- Cloud profiles, secure authorization, remote matchmaking, catalog integrity, verified ownership, ranked competitive achievements, cross-device restoration, moderation and optional message history.
- Rewards for co-op contributions such as careful notes or helping complete a board should not incentivize spam or risky Sudoku moves.
