## Scope

A cohesive cream/forest/gold native visual system, original grid emblem and adaptive launcher icon; mode cards and immediate saved-Solo Resume; compact Daily access; persistent Play/Records/Collection/Settings destinations. Collection has live local style samples and visible unlock requirements; records have a readable overview; settings put name, haptics, display and optional assistance in focused panels.

Play uses a framed classic 9×9 board, selected-cell context, clear digit counters and icon-led tools. The board is sized from same-pass measurement of surrounding text; landscape uses a controls rail from 520dp and short narrow windows can scroll the whole interface. Large-text multiplayer headers reflow to keep room code, Copy, Chat and Help reachable. Completed puzzles use the full results width instead of an empty controls rail. Joining retains manual address/code and nearby discovery, with IME Next targeting the code field and Done submitting only when valid. Solo Home/back saves/returns directly; multiplayer leave/replacement protection remains.

No engine, save/recovery, rating, result-fairness, hidden-opponent projection or LAN transport source changed. Schema1, protocol5 and the existing QA package remain compatible at the data/protocol level. APK signature compatibility is a separate requirement.

## Acceptance limits and decisions

- This is a QA presentation milestone, not a Play release or repository promotion. Retain a draft PR stacked on v0.10C; integration/main promotion is separate.
- Physical two-phone same-Wi-Fi, reconnect, privacy-projection and Split Clues release acceptance remain deferred at the user's request. Native hosted-room smoke checks do not replace that gate.
- Newer Android runtime, physical TalkBack and tablet acceptance remain open. The prior API35 software boot failure is not reclassified as an app pass/failure.
- Existing local recovery remains device-only; clearing data/uninstalling can erase progress. No backup/export/migration or production-signing feature was added.
- The author owns final native appearance inspection and documentation acceptance; the reviewer did not independently run the tests. Unchanged engine/storage correctness remains supported by the observed core/native regression suite rather than a new exhaustive code audit. Existing chat-sheet runtime layout is exercised by smoke but not certified across every keyboard/device.
- Deferred review minors: none. Remaining lint advisories are listed above.

Detailed execution history and decisions: [work log](V0.10D_WORK_LOG.md). Android's [size callback guidance](https://developer.android.com/reference/kotlin/androidx/compose/ui/layout/onSizeChanged.modifier) informed same-pass sibling measurement.
