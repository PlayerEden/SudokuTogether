# Sudoku Together v0.8E — Solo UX and Fair Records

Status: **build and Android emulator QA passed**, actual physical-phone checks pending. Branch `polish/v0.8e-solo-fairness`, based on verified v0.8D `development`. This is a focused polish pass, NOT a new game or shared framework extraction.

## Changes

1. Removed duplicated Solo timer in the status banner. Time remains visible once above the board; the status banner now reports filled squares.
2. Improved native onboarding/help for Solo Hint, the optional Clean pencil marks setting, Undo restoring notes, and assisted versus unassisted recording. Help remains available from the home and puzzle screens.
3. Enlarged/help-labeled the question-mark action to a 48dp touch target and gave the Hint action an explicit accessibility description and 48dp minimum touch height. This is a **focused control audit**, not a claim of full TalkBack or 200%-font certification.
4. Added pure `PersonalPlay.soloSummary()`: counts/best times for unassisted and assisted Solo runs, globally and for each Easy/Medium/Hard tier, with deduplication and Legacy handling. No change to saved record schema or values.
5. Profile shows distinct Unassisted and Assisted counts and best times. A hint-assisted 40-second solution **cannot overwrite** a 10-minute unassisted personal best. If an older saved record lacks a difficulty it remains part of overall unassisted results, not arbitrarily assigned Easy.
6. Recent Solo finishes show explicit Unassisted or Assisted classification. Multiplayer finish labels remain unchanged.
7. Existing Quick Thinker achievement eligibility is unchanged (historically included all Solo solves), with wording clarifying its assistance policy. Previously unlocked achievements/cosmetics are not retroactively revoked.
8. Android QA version bumped to `0.8.0-dev5`, code 12; `.qa` application ID and LAN wire protocol v5 unchanged.
