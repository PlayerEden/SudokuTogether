## What changed

1. Native home screen has accessible Easy/Medium/Hard selection and remembers the preference.
2. New Solo, Co-op and Versus games generate puzzles through the deduction-only rated supplier (no deceptive relabeling or automatic difficulty downgrade); generation runs in background Android dispatcher.
3. Resuming an old game uses that existing saved board. Hosting a rematch keeps the active room's chosen level.
4. `Puzzle.difficulty` and `GameRecord.difficulty` default to null in serialization, keeping older saved sessions and game history valid and explicitly labeled **Legacy**.
5. Guest's canonical host-supplied puzzle carries the difficulty; protocol bumped v4 → v5 for clear error when two phones use incompatible versions. Both phones must install v0.8C QA.
6. Solo record summary has per-difficulty completion counts/best times; recent finishes show their level.
7. Tests include historical JSON with no difficulty, saved rated puzzles, host-to-guest projections, and Android selection behavior.

1. Add candidate-based hint suggestions using the human technique engine, and *display* an explanation with a chosen cell; do not reveal an entire solution to the opponent.
2. Add optional automatic pencil-mark cleanup and assist toggles. Keep the default classic Sudoku experience intact, avoid accidental deductions from hidden information, and decide how assisted runs affect personal records.
3. Test resume, undo, completion, and old save migration after assists. Avoid making hints mandatory.

5. Then finish v0.10 replayability and v0.11 branding, accessibility and Play Store preparation.
