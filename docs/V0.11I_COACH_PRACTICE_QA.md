# GridMates v0.11I Coach practice QA

November 8, 2026. Open **How to play → Coach practice** from Home. Each lesson asks for one placement or candidate removal. **Show why** highlights the real Coach deduction, and **Practice again** resets the exercise.

| Lesson | Move |
| --- | --- |
| Only one digit fits | Place the only digit that fits the outlined square. |
| Only one square fits | Place a digit with only one possible square in its unit. |
| Locked candidate | Cross off a number that belongs in the part of the box covered by a line. |
| Naked pair | Cross off a candidate reserved by a pair elsewhere in the unit. |
| Hidden pair | Cross off an extra candidate in a square reserved by the pair. |
| X-Wing | Cross off a candidate outside the four squares that form the pattern. |

Elimination lessons show the current candidate notes. Hidden pair offers **Show setup steps** for the three earlier deductions used to prepare its notes. The practice dialog keeps choices and feedback in its own screen state and reads the equipped board and number style.
