# Sudoku Together v0.6 — touch and puzzle feel

Branch: `polish/v0.6-puzzle-feel`, stacked on the passing v0.5 native UX branch.

## Scope

This is a **small native gameplay-quality pass**, not a Sudoku rule or networking change.

- **Digit tray:** every 1–9 button shows the remaining number of placements (9 minus current visible occurrences), including starting clues. The number on the selected cell gets a subtle outline and fill in the tray so it's easier to orient visually. A remaining count of zero is informational, **not an input lock**; players must still be able to correct wrong entries.
- **Tactile feedback:** light system-aware Android haptics when choosing a square, number or Notes/Erase/Undo. Enabled by default, user can turn it off in the local profile's **Touch feedback** switch. This setting persists across navigation and app restarts.
- **Host code sharing:** one-tap **Copy code** action on the active room status strip. Nearby discovery and manual host-address joining remain available. This copies only the temporary room code, not the host's IP address.
- **Less redundant in-game branding:** the play header reads Solo, Co-op or Versus, while the home screen retains the game title.
- **Guidance:** the built-in rules sheet explains what the number-tray counters mean.
- **Visual QA:** dedicated `NativeScreenshotTest` captures the actual Compose app content, free of transient system-app dialogs that affected raw ADB screenshots on cold emulator boot.
- **Version:** Android v0.6.0-dev, code 6; debug package remains separately installed under `.qa`.

## QA targets

- Compile Android instrumentation tests, run core/Android unit tests, lint and assemble debug APK.
- Run the full Android instrumentation set, including screenshot capture.
- Read the native screenshot quartet: Solo home, Co-op selection, unsolved Sudoku screen, selected Sudoku cell.
- Test on real small-screen Android phone with large font setting, especially the two-line digit tray, board visibility without excessive scrolling, and access to Notes, Erase and Undo.
- Have two people test host code copying and entering the code on the second phone, reconnect after app interruption, and verify chat and authorship in co-op.
- Confirm the phone's global vibration-disabled state and the profile Touch feedback switch both behave correctly.

## Cautions

The default system haptic API respects Android configuration; no custom vibration permissions or audio are added. The game deliberately does not automatically erase numbers when digits are exhausted. The counter represents visible placements, not guaranteed mathematical correctness. Offline local records and the default signed app are not modified by installing a QA debug APK.
