## Changes

- Local commits validate all progress and Undo fields, sync/finish AtomicFile writes and verify committed bytes before changing memory. A last-good private snapshot supports recovery. Nonmutating bounded reads honor legacy `.bak` without promoting `.new`; every affected primary/recovery source is preserved before reconciliation. Unrecoverable or unpreservable progress blocks saving and keeps its explanation after hosting/Home/Profile. No automatic reset.
- Undo primary targets must be editable; related note snapshots must be distinct editable peers with empty values and plausible revisions. Old JSON/default fields and valid legacy Undo remain supported.
- Initial profile loading runs off-main. New local puzzles are prepared outside the intent lock, then the captured generation is checked while persistence and UI publication share the navigation boundary. Superseded Solo/Daily starts cannot replace newer saves; requested difficulty is captured at the initiating action.
- Daily updates retain unfinished boards within 128 slots and the newest 31 completed review boards. The accepted finish is retained independently of archive eviction; completion records stay idempotent and normal Solo independent.
- Android 8-compatible date conversion fixes a startup crash. History adapts dates/actions at 200% text, keeping 48dp targets. Older Daily results use correct wording. Only the Solo clock label recomposes each second; canonical saved time remains monotonic.

## Remaining gates and decisions

- Existing schema 1/profile identity and LAN protocol 5 stay compatible. The earlier v0.10B checkpoint is preserved. Draft integration is the already-approved route; main/development promotion is separate.
- Debug signing can differ from older QA installations. Do not uninstall a progress-bearing app to bypass a signing conflict. Durable signing custody and an explicit upgrade/export path remain v0.11 work.
- The API35 software emulator failed its 600-second cold boot before any tests; newer-Android runtime acceptance remains open. No pass or app failure is inferred from that infrastructure limit.
- Two-phone same-Wi-Fi co-op/versus/reconnect acceptance remains deferred at user request, so Split Clues and multiplayer release certification remain gated. Physical TalkBack/tablet/device accessibility and production signing/API/brand/privacy/Play testing remain later work.
- Local recovery is device-only and can omit recent changes; it is not cloud/uninstall backup or an absolute power-loss guarantee. No destructive reset/export UI is introduced.
- Completed review boards beyond 31 cannot reopen after process death; separate records remain within the existing 10,000-result bound. Oldest data can age out; unfinished Daily boards remain protected within 128 slots.
- Deferred minor: at 200% font the ownership/Time labels can touch. Clock digits and scrolled finish controls remain readable.
