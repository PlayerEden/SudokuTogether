## Behavior and decisions

- Daily Challenge appears as a distinct home card with the **device's local ISO calendar date**. One 9×9 **Easy** challenge per day, generated deterministically from SHA-256 of a versioned daily salt and date, verified as uniquely solvable and logically Easy by the existing grader.
- It works completely offline; a matching date gives the same puzzle on every install of this exact daily algorithm. Time zone and manual device-date changes affect what counts as "today"; an active board is not silently replaced at midnight.
- Uses independently persisted `DailyProgress(date, SoloProgress)` entries (up to 31 locally stored date slots). **Regular `activeSolo` is untouched**, and existing multiplayer rooms/saves are untouched. Past unsolved dates can remain in the limited local history, but the current home card opens only today's date. Oldest daily progress entries age out after 31 different daily dates; completed results remain in normal record history (up to existing 10,000 result limit).
- Daily saves include pencil notes, Undo, optional hints and notes cleanup, active elapsed time. Completing one generates a separate `GameRecord` with `mode = daily`, `dailyDate`, difficulty and assisted flags. Daily completions do **not** increment ordinary Solo completion/best-time stats; daily completion is idempotent.
- Returning to today's challenge resumes the existing board, and reviewing a completed challenge cannot create a second attempt that day. Standard Solo and Co-op/Versus keep current UI, rules and protocol v5.
- Older local profile JSON has defaults for new daily fields, and the app validates daily saves before loading them; old profiles remain readable.
- Android QA package remains `.qa` and version becomes `0.10.0-dev1` / versionCode 13. No new runtime permissions, accounts, network services or internet-required features.

## Future refinements

- A daily streak is optional and should not be coercive; consider separately tracked challenges and date-based completions, without pretending local records represent world rankings.
- Later tier rotations should be introduced only with measured grader distributions and versioned generation rules; do **not** retroactively alter puzzles for past dates.
- A daily-mode leaderboard requires a trusted backend and anti-cheat/ranking policy, deliberately deferred beyond local release.
- User has postponed physical two-phone multiplayer test. **Do not claim it passed**, and do not begin Split Clues without host/guest privacy and real-device testing.
