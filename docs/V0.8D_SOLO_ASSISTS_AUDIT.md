## Implemented — focused, safe first slice

1. **Read-only, explainable hint**: Solo puzzle has an optional **Hint** button. It analyzes exactly the visible 9×9 values with the existing no-guess human technique solver. When a unique and logically valid deduction exists, the app highlights a square and opens a dialog with the suggested number and a short reason. It **does not fill** that square.
2. **Invalid-grid safety**: Wrong entries that make the current Sudoku grid unsolvable get no hint, rather than a guessed or leaked answer. All computation stays on the Android worker dispatcher.
3. **Durable assist accounting**: Seeing a successful hint increments `SoloProgress.hintsUsed` using the existing atomic local profile save. A completed solo `GameRecord` carries `assisted` and `hintsUsed`; older saved games and historical records default to zero/false.
4. **Optional pencil-mark cleanup**: `Clean pencil marks` in profile defaults **OFF**. With the setting enabled, placing a value on a Solo grid removes that candidate from empty squares sharing its row, column or 3×3 box. The move and all changed notes form a single undoable unit using a backwards-compatible `SoloUndo.relatedBefore` map. Undo restores the note state and original value.
5. **Gameplay constraints**: Assistance is SOLO ONLY for this slice. Co-op and versus retain their original rules; **no hints, candidate cleanup or solution leakage between players**. Competitive, Split Clues and any future hidden-information game modes need their own explicit fair-play policy.
6. **UX**: Hint dialog explains the suggested step and assistance status. Profile includes opt-in preference. Completed assisted solo records show `Assisted` in Recent Finishes. Haptic setting, difficulty choices and dock remain intact.

## Limitations / follow-ups

- A clue-free misfilled board is not assisted; wrong entries prompt a clear message to inspect/Undo. Current step explanations cover singles and optionally a prior locked-candidate / naked-pair reason; they are not a full step-by-step teaching curriculum.
- Existing aggregate 'Best time' cards may include older and newer assisted runs. A later fairness polish can make unassisted and assisted records more distinctly comparable, without deleting any historical results.
- Automatic pencil cleanup only applies to Solo; making it multiplayer-safe would require an explicit room-wide rule and host-authoritative multi-cell operation rather than client-side mutations.
- Test an upgrade from the user's previous QA install (signing certificates may differ across GitHub runners), and confirm old progress remains when Android accepts the update. Never recommend uninstalling without warning about local save loss.
- Real phone QA: Easy/Medium/Hard hints, wrong number, notes cleanup and Undo, resume after process restart, 200% font, narrow screen. Real two-phone reliability remains v0.9A.
- Do not claim the app is Google Play-ready. Remaining roadmap: final assist polish, LAN physical test, QR/join, Split Clues after LAN gate, daily/replay features, distinct brand and store signing/privacy.
