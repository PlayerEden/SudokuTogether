## Coach

In Solo or Daily, **Hint** opens a board preview with the target outlined. **Show why** adds the supporting squares and exact candidate removals. **Next step** follows the same deduction path through the first placement when one is available. When a wrong entry blocks the proof, **Check my work** remains an explicit solution check. The preview reads the current grid and the player enters each move. Browsing the proof counts as one hint. The app remembers recently viewed boards during play, including a board revisited with Undo.
